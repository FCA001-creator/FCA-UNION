# FCA UNION GROUPS

Frontend source for the FCA UNION GROUPS interface prototype.

## Stack
React, TypeScript, Vite, Tailwind CSS and Lucide icons.

## Run locally
```sh
npm install
npm run dev
```

## Important prototype notice
FCA UNION GROUPS is a simulated interface prototype, not a bank, credit union, lender, or licensed financial institution. Balances, account details, credit scores and transaction entries are simulated and are not real funds, deposits, credit reports, or financial records. No real payments, transfers, or banking services are provided. Do not enter real financial credentials or sensitive personal information.

The administrator sign-in endpoint is hosted by AppDeploy. Configure `FCA_ADMIN_PASSWORD` as a server-side secret in AppDeploy. Never commit passwords, API keys, or other secrets to GitHub.
